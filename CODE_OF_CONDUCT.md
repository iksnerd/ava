# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The short version:

- Be respectful. Disagree with the code or the idea, not the person.
- No harassment, discrimination, or personal attacks, in issues, pull requests, reviews, or anywhere else the project is discussed.
- Assume good faith, and say plainly when something is unclear instead of guessing at motives.
- Do not publish other people's private information.

## Reporting

To report a problem, email me@iksnerd.xyz. Reports are read by the maintainer only and are kept private. Vulnerabilities are a different channel: see [SECURITY.md](SECURITY.md).

## Enforcement

The maintainer may remove, edit, or reject comments, commits, issues, and pull requests that break this code, and may temporarily or permanently ban a contributor for behavior they judge inappropriate. Enforcement follows the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
